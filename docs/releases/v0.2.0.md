# RustRobotics v0.2.0

This GitHub-only release expands RustRobotics from an algorithm collection into
a reusable estimation and autonomy workspace.

Highlights:

- `no_std` Lie-group and Kalman-family foundations;
- robust factor graphs with dense LU, block-sparse PCG and BA Schur solvers;
- SE(2)/SE(3) g2o pose graphs, IMU preintegration, bundle adjustment and
  geometric ICP;
- EuRoC and KITTI loaders plus an offline IMU → BA → SE(3) VIO replay;
- pinned numerical parity tests against MathematicalRobotics;
- reproducible 1k/5k/10k pose benchmarks and pure-Rust SVG/GIF assets;
- native/WASM playground, ROS2/Gazebo smoke tests and embedded CI.

The release commit passed workspace tests, strict Clippy, rustdoc, no_std,
WASM, dependency audit, package preflight, Pages deployment and ROS2 Smoke.

This release intentionally does **not** publish packages to crates.io. Use the
Git tag directly:

```toml
[dependencies]
rust_robotics = { git = "https://github.com/rsasaki0109/rust_robotics", tag = "v0.2.0" }
```
