# rust_robotics_mapping

Mapping algorithms for the RustRobotics workspace, including occupancy grids,
NDT maps, ray casting grid maps, Gaussian grid maps, point cloud sampling, and
geometric feature extraction. The IMLS module provides PCA local normals and
Gaussian-weighted implicit surface projection for 2D scans.

```toml
[dependencies]
rust_robotics_mapping = "0.2"
```
