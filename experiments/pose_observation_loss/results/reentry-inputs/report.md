# 解除直後の再発動を入力の変化に分ける診断

[前回の診断](../entry-cycles/report.md)で見つけた短い再発動27区間を調べると、24区間では観測誤差の変化が判定余裕を最も縮めていました。残る3区間では、速度に応じた追加余裕の増加が最大でした。今回の対象では、追加余裕の調整だけでなく、時刻を揃えた観測の平滑化を次の比較候補にする根拠があります。改善効果を示す新しい走行実験ではありません。

## 対象と方法

前回固定した、保持を失った10組のうち7例にある27区間をすべて使いました。独立ノイズが14区間、相関1秒が13区間です。対象はガード解除時の実指令速度が正、途中に欠落待機がなく、1秒以内かつ移動0.1未満で再発動した区間です。結果を見て区間を差し替えていません。

判定余裕は「正確な停止予測距離−ガード開始閾値」です。正なら開始条件を通過し、0以下ならガードが発動します。27区間の平均は、解除時の+0.22853から再発動時の−0.02591へ変わりました。解除時には実際の、より厳しい解除閾値も通過していました。

停止予測の入力を次の4群に分け、各群について解除時の値と再発動時の値を入れ替えた16通りを計算しました。

- 真の姿勢：位置とヨー。実際の移動・旋回に対応します。
- 観測誤差：位置・ヨーのノイズとドリフトの和。
- 初期速度：停止予測の積分開始時の測定速度。
- 予定指令：予測用の目標速度と操舵。

入力間の相互作用があるため、1つの入れ替え順だけで寄与を決めません。全24順序での距離変化を平均し、各群へ配分しました（Shapley配分）。これに、ノイズ尺度・観測年齢による基礎閾値の変化と、速度依存の追加余裕の変化を加えます。速度が予測軌道へ与える寄与と、閾値へ与える寄与を分けています。

これら6項の和は、各区間の判定余裕の変化に一致します。混ぜた入力が実際に同時に起きることや、その間をつなぐ軌跡が存在することは仮定していません。真姿勢と真の観測誤差はオフライン診断にのみ使い、制御へ渡していません。

## 判定余裕の変化

負の値は再発動へ近づけ、正の値は余裕を増やします。「最大の縮小」は各区間で最も負だった項の件数です。

| 項目 | 平均の余裕変化 | 最大の縮小 / 27 |
|---|---:|---:|
| 実際の移動・旋回 | +0.00109 | 0 |
| 観測誤差 | −0.20162 | 24 |
| 初期速度による予測軌道の変化 | −0.00569 | 0 |
| 予定指令の変化 | +0.00451 | 0 |
| 基礎閾値の変化 | −0.00470 | 0 |
| 速度依存の追加余裕 | −0.04803 | 3 |
| 合計 | −0.25444 | 27 |

独立ノイズの14区間では観測誤差が最大だったものが13、追加余裕が1でした。相関1秒の13区間では、それぞれ11と2でした。観測誤差にはドリフトとヨーも含み、独立した位置ノイズだけの効果ではありません。

解除時の速度は0〜0.00268、再発動時は0.00337〜0.38581でした。速度とともに追加余裕は増えていますが、今回の多くの区間では、実際の移動や速度による予測形状の変化よりも、観測された姿勢の誤差変化が大きく距離を縮めています。これは当該配分での結果で、物理的な因果効果の推定ではありません。

## 1つの入力を解除時の値に固定した場合

再発動時の他の入力を保ち、1群だけ解除時の値へ戻した局所計算でも確認しました。「通過」は再計算した距離が開始閾値を2×10⁻⁸より大きく上回る場合です。

| 解除時へ戻す入力 | 開始条件を通過 / 27 |
|---|---:|
| 真の姿勢 | 7 |
| 観測誤差 | 27 |
| 予測軌道の初期速度だけ | 5 |
| 予定指令 | 0 |
| 基礎閾値 | 12 |
| 速度依存の追加余裕だけ | 21 |
| 初期速度と追加余裕の両方 | 22 |

件数は重なり得ます。観測誤差を解除時に固定した場合の余裕は+0.02781〜+0.40348でした。27区間すべてで通過しても、解除時の誤差を制御側で知って固定できるわけではありません。解除の判定を通過した時点を選んでいるため、誤差がその時点で有利な向きへ偏る選択も含みます。通常走行中の誤差分布や全失敗例へ一般化しません。

## 次に比較する候補

この27区間については、速度余裕だけの調整を続けるより、移動を補償して複数観測を同じ時刻へ揃え、開始・解除の両判定へ共通の平滑化した姿勢を渡す候補を優先します。静止中の平均姿勢をそのまま持ち越すと移動との時刻ずれを作るため、動的な時刻補正も比較対象に含めます。

これは次の検証候補で、今回は実装・採用していません。元の `joint` との新規シードによる対比較で、接触、待機、短い再発動、10秒保持を同時に確認する必要があります。前回の短い再発動がない3失敗例や、末尾の長い復帰待機も、改善の評価から外しません。

## 検証と再実行

16通り×27区間の432予測を計算しました。この中の54予測は実際の解除・再発動の端点で、前回の正確な幾何監査と最大差1.29×10⁻⁹で一致しています。丸められた位置・誤差を足し直す差を考慮し、照合許容値を10⁻⁸にしました。各区間で寄与の和と実際の余裕変化の差は10⁻¹⁰未満です。

入力経路、シミュレータ、シード、走行要約と生軌跡のハッシュを保存済み診断に照合しました。解析を再実行し、全CSVと実行情報のバイト単位の一致も確認しました。加算・相互作用の既知解、静止時の移動と誤差の幾何、移動中の線分距離を含む新しい5テストと、再利用する区間・幾何の既存14テストが通過しました。シミュレータとライブラリの制御は変更していません。
