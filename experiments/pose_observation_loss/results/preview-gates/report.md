# 復帰直線の追加後に増えた待機と再発動

[前回の復帰直線比較](../recovery-preview/report.md)で保持が減った新規162組を、保存済み軌跡から診断しました。単独ガード解除を判定している時間の76.57%では、ほかの解除条件を満たし、追加した終端直線だけが通っていませんでした。一方、欠落からの同時復帰では94.34%が、追加直線以外の条件で止まっていました。短い再発動237回は全例で終端直線の予測距離が低下しており、余裕の時間増加だけでは再発動を説明できません。

これは同じ記録上で条件を分解した診断です。直線条件を外すと以降の姿勢・速度・観測が変わるため、解除を緩めれば保持が改善するという結果ではありません。制御や既定値は変更していません。

## 対象と判定区間

前回固定したseed259〜261、独立ノイズと相関1秒、各81例の `recoverable` 全162走行を対象にしました。元の `filtered` で保持できたのに候補で失った34組は、従来群の軌跡も確認しました。既知シード群は今回の診断に含めていません。

1行は0.02秒の指令区間です。判断前のガードが有効で欠落復帰が保留されていなければ「単独解除」、欠落復帰が保留されていれば「同時復帰」とします。欠落を新たに検出した行も後者です。ガード開始だけの行は単独解除タイマーに加えず、解除指令の行は含めます。同じ経路の連続区間を1エピソードとして集計します。

`m = 0.5 + 2√2×sigma + 0.02×観測年齢` とすると、停止予測は `Dstop > m + 0.05`、追加直線は `Dterminal > m + 0.15` が解除条件です。単独解除はさらに判断前の速度の絶対値0.02以下、同時復帰はそれに加えて観測年齢、実際の復帰直線と地図境界、観測数、正の予定速度を満たす必要があります。連続確認はそれぞれ0.5秒と1秒です。

時間は次の優先順で排他的に分類しました。

1. **ほかの条件で停止**: 停止予測・終端直線以外の条件が1つ以上不成立。両幾何の成否はここでは分けません。
2. **両方で停止**: ほかの条件は成立し、停止予測と終端直線がともに不成立。
3. **停止予測だけ**、**終端直線だけ**: ほかの条件と片方の幾何が成立。
4. **全条件成立**: その行の解除条件がすべて成立。連続時間の達成前も含みます。

この分母は解除判定区間です。走行時間や、前回の「欠落待機またはガード」の和集合とは異なります。

## 短い再発動

解除指令の速度が正、途中に欠落待機がなく、次のガード開始まで1秒以内かつ移動0.1未満という前回と同じ定義です。独立89回、相関148回の計237回が74走行にありました。うち235回は停止予測を通過していて終端直線だけで発動し、残る独立ノイズの2回は両方が不成立でした。

| 指標 | 最小 | 中央値 | 最大 |
|---|---:|---:|---:|
| 解除から再発動まで（秒） | 0.08 | 0.32 | 0.80 |
| 再発動前の移動 | 0.00153 | 0.03324 | 0.09992 |
| 終端直線の予測距離の変化 | −0.35197 | −0.08913 | −0.04897 |
| 余裕 `m` の変化 | −0.09720 | 0.00600 | 0.01600 |

解除時には全例で終端直線の開始余裕が0.05より大きく、再発動時には全例でその余裕が負になっていました。解除時の終端距離を固定し、再発動時の `m` だけに置き換えた計算では、237回すべてが直線の開始条件を通過します。したがって、余裕の時間増加だけでは今回の再発動を説明できません。

この計算では、姿勢推定の変化、予定速度・操舵による停止予測の変化、物理移動を分離していません。小さな移動距離から観測誤差だけを原因と推定したり、距離を固定する制御で再発動が消えると解釈したりはできません。

## 保持を失った34組

比較する時間窓を、従来群が保持を完了した時刻までにそろえました。34組すべてで候補の待機が増えており、その窓内の平均待機は30.84→97.57秒でした。独立25組では30.08→97.61秒、相関9組では32.96→97.46秒です。待機は欠落待機とガードの和集合で、重なりは1回だけ数えます。

候補で真の目標領域に入ったのは34組中1組だけでした。独立・random・seed259・maze・A*で、最初の進入は177.02秒です。残り33組は180秒までに真の目標領域に入りませんでした。待機増と進行不足は確認できますが、開始と解除のどちらの変更が保持喪失を引き起こしたかは、この比較だけでは確定しません。

## 検証と再実行

新規162走行と保持喪失34組の従来軌跡について、計1,424,915物理区間を照合しました。候補の全ステップで姿勢フィルタ、ガード遷移、同時復帰タイマー、距離の組合せを確認しました。短い再発動の両端474地点では、停止軌道と終端直線を独立に再計算し、記録された判断と一致しました。

追加した境界・状態遷移・連続時間の6テスト、既存の幾何20件、区間7件、停止例診断5件の計38テストが通過しました。Python整形・構文チェックも通過しました。集計を再実行し、6つのCSVと実行情報のバイト単位の一致を確認しました。今回シミュレータの変更や再走行は行っていません。

[READMEの再実行手順](../../README.md#diagnose-terminal-preview-release-gates)を使用してください。[cases.csv](cases.csv)、[episodes.csv](episodes.csv)、[short-reentries.csv](short-reentries.csv)、[checkpoints.csv](checkpoints.csv)、[lost-pairs.csv](lost-pairs.csv)、[summary.csv](summary.csv)に集計を、[sources.json](sources.json)に入力・生軌跡・スクリプトのハッシュを保存しました。シミュレータは前回のSHA-256 `c108d0e20cdac94d8cd2fe54125db1b426598e785af7700bbcc0819bd5abf7f1` と同じです。

次の制御比較では、開始条件を固定して解除条件だけを変える比較が必要です。今回の結果から解除条件の緩和を採用したり、同時復帰の停滞まで解消すると判断したりはできません。同じ地図・少数シードの組合せ、正確な測定速度と車体モデルを用いる実験という制約も前回と同じです。
