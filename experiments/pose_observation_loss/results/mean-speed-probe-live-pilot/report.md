# 平均位置を速度プローブへ渡す閉ループ試験

未使用seedを使った108ケース・54ペアの試験で、元位置方式と平均位置方式の保持成功はともに24/54でした。成功へ変わったペア、失敗へ変わったペアはともに0件です。両方式とも残る30ケースは180秒で時間切れとなり、接触と境界外への退出は0件でした。今回の試験では、保持成功の増加を確認できませんでした。

平均位置は36ケース・17,862判断で実際に選択されました。元の82列の軌跡ログには28ペアで差が生じ、そのうち4ペアで終端の目標距離も変わりましたが、この4ペアはいずれも時間切れのままでした。オプションは実験用の既定falseを維持します。

生成器・実行器・監査器・テストを`6497a30a64ae2a2b677dfa1e53f648f217800b78`にコミットし、作業ツリーがクリーンな状態で2026-10-18に本試験を開始しました。元のシミュレーター、制御・型の実装、マニフェスト、Cargo.lock、地図・経路、既存の監査関数など27入力のハッシュを固定しています。先行する19リセットの幾何結果は既知ですが、今回の観測seedはそれらとは異なります。

## 試作の変更点

元ソースをその場で編集せず、ハッシュを照合してから一意な文字列アンカーで実験用ソースを生成しました。[candidate.diff](candidate.diff)は全変更を保持します。Cargoのlockedビルドから元exampleと正確なcore/controlのrlibを取得し、生成したソースをそのライブラリに対してコンパイルしました。依存関係や通常のライブラリの既定動作は既存のままです。

追加の最後の引数`MEAN_SPEED_PROBE`は省略時falseです。trueにはjoint recoveryとaveraged recoveryが必要です。次の条件がすべて成立する判断だけで、速度探索に渡すx/yを既存のその時点のrecovery_x/recovery_yへ置き換えます。

- すでにsafety_pausedである。
- 測定速度の絶対値が0.02以下である。
- 観測年齢が1.5秒以下である。
- 既存の定常平均窓に10サンプル以上ある。

窓の蓄積・リセット方法を引き継ぎ、新たな平均窓は作っていません。元の測定yaw、速度、ホイールベース、予定操舵、速度余裕量、地図、speed_free_distance関数本体を保持しています。既存の停止・解除・追従計算もそのままです。条件を満たさない判断は元の測定位置を使います。

別のspeed-probes.csvへ、全判断の入力、選択、平均、探索距離、速度上限、実際の制御と物理状態を小数点以下17桁の指数形式で記録しました。真値は照合用のログ出力であり、新しい制御入力ではありません。元の82列のtrajectories.csvとresults.csvの形式は維持しました。

## 再実行と保存場所

Python 3.12の標準ライブラリと有効化したRust/Cargoを使用します。クリーンなコミット済みチェックアウトで、出力先はそれぞれ存在しないリポジトリ外のパスを指定してください。実行器は出力先の親に2 GiB以上の空きを要求します。

```bash
python3 -B experiments/pose_observation_loss/run_mean_speed_probe.py \
  --output /tmp/mean-speed-probe-raw
python3 -B experiments/pose_observation_loss/analyze_mean_speed_probe.py \
  --raw /tmp/mean-speed-probe-raw --output /tmp/mean-speed-probe-audit-1
python3 -B experiments/pose_observation_loss/analyze_mean_speed_probe.py \
  --raw /tmp/mean-speed-probe-raw --output /tmp/mean-speed-probe-audit-2
```
